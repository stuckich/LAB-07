\# Проект: Набор утилит обработки данных (functions.py \& main.py)



Данный проект состоит из двух модулей: `functions.py` (содержит чистые функции для вычислений и обработки текста) и `main.py` (скрипт для интерактивного взаимодействия с пользователем и демонстрации работы).



\## Описание функций (`functions.py`)



\### 1. `sum\_digits(number)`

\* \*\*Что делает:\*\* Вычисляет сумму всех цифр переданного целого числа.

\* \*\*Как работает:\*\* 

&#x20; 1. Сначала берется `abs(number)` (модуль числа), чтобы корректно обрабатывать отрицательные значения при делении.

&#x20; 2. С помощью цикла `while` и операции взятия остатка от деления (`% 10`) извлекается последняя цифра числа и добавляется к общей сумме.

&#x20; 3. Число уменьшается путем целочисленного деления (`// 10`). Цикл продолжается, пока число больше нуля.

&#x20; 4. Для `0` цикл не выполнится, и функция вернет исходное значение суммы: `0`.



\### 2. `average(numbers)`

\* \*\*Что делает:\*\* Рассчитывает среднее арифметическое элементов списка.

\* \*\*Как работает:\*\*

&#x20; 1. Проверяет, не является ли список пустым (`if not numbers`). Если пуст — возвращает `None`.

&#x20; 2. Если в списке есть элементы, возвращает результат деления суммы элементов на их количество (`sum(numbers) / len(numbers)`).

&#x20; 3. Не изменяет структуру и значения исходного списка.



\### 3. `normalize\_text(text)`

\* \*\*Что делает:\*\* Очищает строку от лишних пробелов.

\* \*\*Как работает:\*\*

&#x20; 1. Метод `.split()` разбивает строку на список слов, автоматически удаляя любые пробельные символы (включая табуляцию и переносы строк) по краям и между словами.

&#x20; 2. Метод `" ".join(...)` собирает слова обратно в строку, вставляя между ними строго по одному пробелу.

&#x20; 3. Исходный регистр символов полностью сохраняется.



\### 4. `select\_numbers(numbers, threshold)`

\* \*\*Что делает:\*\* Фильтрует список целых чисел по двум критериям: число должно быть \*\*чётным\*\* и \*\*строго больше\*\* заданного порога (`threshold`).

\* \*\*Как работает:\*\*

&#x20; 1. Создает новый пустой список.

&#x20; 2. Итерируется по исходному списку. Для каждого элемента проверяется условие: `num % 2 == 0 and num > threshold`.

&#x20; 3. Если условия выполняются, элемент добавляется в новый список. Это гарантирует сохранение оригинального порядка и дубликатов.



\---



\## Инструкция по запуску (`main.py`)



Скрипт `main.py` служит консольным интерфейсом. При запуске он:

1\. Запросит у вас целое число для проверки суммы цифр.

2\. Попросит ввести текст со случайными пробелами для демонстрации нормализации.

3\. Предложит ввести список чисел через пробел.

&#x20;  \* Если нажать \*Enter\* (передать пустую строку), программа выведет `Среднее арифметическое: Нет данных`.

4\. Попросит ввести число-порог для демонстрации работы фильтрации.

5\. Автоматически запустит \*\*контрольные примеры\*\*:

&#x20;  \* Тест из ТЗ: список `\[-5, 0, 2, 5]` с порогом `2` (ожидаемый результат `\[]`).

&#x20;  \* Дополнительный тест с совпадениями: список `\[12, 14, 3, 8, 12, 4]` с порогом `5` (ожидаемый результат `\[12, 14, 8, 12]`).



\### Запуск проекта:

```bash

python main.py

```
